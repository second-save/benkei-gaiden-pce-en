# Benkei Gaiden (PC Engine) — English Translation

Unofficial archival and historical English fan translation of ***Benkei Gaiden*** (*弁慶外伝*, PC Engine HuCard, Sunsoft, 1989).

Work in progress — see `docs/status.md`.
